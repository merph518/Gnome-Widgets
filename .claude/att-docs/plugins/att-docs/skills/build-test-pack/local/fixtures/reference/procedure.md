# Synthetic Build Test Pack Procedure

Run intake, then Phases 1 to 10 in order. Stop at the first failed gate.
Phase 1 confirms understanding; Phase 2 takes rules from included sources only;
Phase 3 classes each rule by the change; Phase 4 analyses impact; Phase 5 decides
every objective; Phase 6 designs one card per decision; Phase 7 groups cards into
sets; Phase 8 builds the workbook; Phase 9 reviews it; Phase 10 records gaps.
